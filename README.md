# AutoHotspot（自动热点）

装在越狱 iPhone 上的插件。**本机没连 Wi‑Fi，并且蓝牙发现你的另一台 iPhone 就在身边时，自动打开个人热点**；那台手机离开，或者本机连上 Wi‑Fi 时，自动关掉热点。

*A roothide jailbreak tweak that turns on Personal Hotspot when your other iPhone is nearby (via Bluetooth) and this phone has no Wi‑Fi, and turns it off when that phone leaves or Wi‑Fi comes back.*

适合这种情况：两台手机总是一起带，其中一台没有蜂窝网络（比如没装 SIM 卡的 iPhone Air，或者 iPad），出门就要靠另一台开热点。

## 为什么不用系统自带的「自动加入热点」

系统自带的功能靠被连的那台手机通过蓝牙去「唤醒」热点，经常时灵时不灵。原因是：iOS 只有在「个人热点」设置页开着的时候，才让热点能被别的设备搜到，离开这个页面后就搜不到了。

这个插件从开热点的那台手机这边下手：
- 判断「对方在身边」这件事由这台手机自己来做；
- 打开热点时，同时把「能被搜到」打开；
- 如果系统把「能被搜到」关掉，插件会马上重新打开。

## 适用范围

| 项目 | 要求 |
|---|---|
| 开热点的手机 | **roothide 越狱**（Dopamine roothide 或 Bootstrap roothide），A12 及以上芯片（arm64e） |
| iOS 版本 | 在 **iOS 16.0.2**（iPhone 14 Pro）上完整测过。iOS 15 和 16 其他版本大概率可用；iOS 17 及以上没验证 |
| 运营商 | 需要有蜂窝网络，并且套餐允许开个人热点 |
| 被连的设备 | 任意 iPhone 或 iPad，不需要越狱，**必须和开热点的手机登录同一个 Apple ID**（否则蓝牙地址大约每 15 分钟换一次，插件会认不出来） |
| 依赖 | PreferenceLoader |

**暂不支持** rootless（普通 Dopamine、palera1n rootless）和 rootful（checkra1n、unc0ver）越狱。插件用到的是私有系统接口，升级 iOS 后可能失效。

## 安装

1. 从 [Releases](../../releases) 下载最新的 `com.xcode.autohotspot_*_iphoneos-arm64e.deb`。
2. 用 Sileo 或 Filza 安装，或者 SSH 到手机后运行 `dpkg -i 文件名.deb`。
3. 在多任务界面把「设置」划掉，再重新打开。之后就能在「设置」里找到 **「自动热点」**；如果装了插件整理类的插件，就到它的「插件」页里找。

## 第一次使用

1. **被连的设备（比如 Air）上**：进入「设置 → 无线局域网」，把最底部的「自动加入热点」设为 **「自动」**。
2. **让被连的设备记住热点**：在开热点的手机上把热点打开，然后在被连的设备的 Wi‑Fi 列表里，点**带 🔒🔗 图标的那个热点**（不是带电池图标的那个），连接一次。连上后点 ⓘ，确认「自动加入」是开着的。
   - 只有存成已知网络，被连的设备才会自己连上来；如果「忽略此网络」，就要重新连一次。
3. **让插件认识你的设备**：开热点的手机断开 Wi‑Fi，把被连的设备放在旁边，插件会通过蓝牙读取型号（默认 `iPhone18,4`，也就是 iPhone Air），几秒内就能认出来并记住。如果你的设备是别的型号，先在设置里改「型号」，再点「重新识别」。

## 设置项（设置 → 自动热点）

| 分组 | 选项 |
|---|---|
| 状态 | 当前状态、热点连接数、最近一次在附近发现被连设备的时间和信号强度、本机电量、定时状态、最近事件。实时刷新 |
| 开关 | 启用自动热点。关掉再打开可以立即结束冷却 |
| 手动控制 | 立即打开热点：不受定时和电量限制。立即关闭热点：同时进入冷却 |
| 定时 | 开关、开始时间、结束时间、按星期重复。支持跨夜，比如 22:00–07:00。开始和结束设成同一时间表示全天 |
| 规则 | 信号阈值（默认 -80 dBm）、扫描间隔（15/30/60 秒）、离开多久后关闭（默认 3 分钟）、没人连接多久后关闭（默认 5 分钟）、关闭后冷却多久（默认 30 分钟）、Wi‑Fi 关着时是否自动打开 |
| 省电保护 | 电量低于多少时暂停（默认 20%）、低电量模式时暂停。接着电源时不受这两条限制 |
| 目标设备 | 型号、已识别的设备、重新识别 |
| 诊断 | 查看最近 400 行日志、版本号 |

## 工作原理

后台程序 `autohotspotd` 由 launchd 以 root 身份启动，崩溃后会自动重启。它订阅 Wi‑Fi、热点、电量和低电量模式这些系统事件，不靠轮询。

| 当前情况 | 插件做什么 |
|---|---|
| 本机连着 Wi‑Fi（连续 10 秒以上） | 待机，不扫描蓝牙；如果热点是插件开的，就关掉 |
| 没连 Wi‑Fi，热点关着 | 每隔一个扫描间隔，用蓝牙扫 5 秒。发现目标设备且信号强于阈值，就打开热点，并让它能被搜到 |
| 热点开着，有设备连着 | 不扫描 |
| 热点开着，没有设备连着 | 每分钟扫一次。目标设备离开超过设定时间就关热点；设备在旁边但一直不连，就关热点并进入冷却 |
| 热点是你手动打开的 | 不干预 |

用到的私有接口：

- `CBManagerIsPrivilegedDaemonKey`：不加这个选项，后台程序扫描蓝牙收不到任何结果。
- `MISManager setState:`（来自 WirelessModemSettings.bundle）：开关热点。
- `WFClient setMISDiscoveryState:immediateDisable:`（来自 WiFiKit）：让热点能被搜到。
- MobileWiFi 的 `WiFiManagerClient*` 系列函数：读取和设置 Wi‑Fi 开关状态。
- `SCDynamicStore`：订阅 `en0` 和 `com.apple.MobileInternetSharing` 两个键的变化。

## 自己编译

需要 macOS、Xcode 和 [roothide Theos](https://github.com/roothide/theos)。

```bash
make package FINALPACKAGE=1 THEOS=/path/to/theos-roothide
```

| 目录 | 内容 |
|---|---|
| `daemon/` | 后台程序：状态机、蓝牙识别、系统接口 |
| `prefs/` | 设置页 |
| `shared/` | 后台和设置页共用的定义 |
| `probe/` | 调试用的命令行工具，不会打包进 deb |

## 排查问题

- **日志**：`/var/jb/var/log/autohotspot.log`。每一次判断和动作都会记录，设置页里也能直接看。
- **状态文件**：`/var/jb/var/lib/autohotspot/state.plist`。
- **改了设置或升级插件后**：要先在多任务界面把「设置」划掉，新的设置页才会生效。

## 已知限制

- **锁屏后变慢**：开热点的手机锁屏休眠后，系统可能推迟后台定时器，扫描和定时切换会晚一些。
- **短时间内反复断开**：被连的设备在短时间内被断开很多次后，重连会变慢（从几秒变成一分钟左右），这是 iOS 自己的退避行为。
- **信号差的已知 Wi‑Fi**：如果开热点的手机记住了某个信号差的 Wi‑Fi，它会反复连上又断开，每次被连的设备都会短暂断网。在开热点的手机上把那个网络的「自动加入」关掉就好。
- **重启**：重启会丢失越狱，重新越狱后插件会自动启动。
